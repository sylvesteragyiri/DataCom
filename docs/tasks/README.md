# Tasks

One file per **completed** task or feature, added once the work is done. This documents what was built and why, for future reference — it is not a to-do list (see [../ROADMAP.md](../ROADMAP.md) for planned work).

## Naming convention

`task-YYYY-MM-DD-short-description.md`

Example: `task-2026-10-02-app-shell-navigation.md`

## Template

```markdown
# Task: <short description>

**Completed:** YYYY-MM-DD

## What was built
- ...

## Files touched
- ...

## Notes / follow-ups
- ...
```
