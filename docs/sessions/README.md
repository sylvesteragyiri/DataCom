# Sessions

One file per work session with an AI agent, added at the end of the session. This is a log, not a task tracker — it captures what was discussed/decided even if no task was completed.

## Naming convention

`session-YYYY-MM-DD-short-description.md`

Example: `session-2026-09-28-docs-setup.md`

## Template

```markdown
# Session: <short description>

**Date:** YYYY-MM-DD

## What happened
- ...

## Decisions made
- ...

## Open questions / follow-ups
- ...
```
